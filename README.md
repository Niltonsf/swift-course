# Xcode Course

My projects from the [Rocketseat Swift journey](https://app.rocketseat.com.br/jornada/swift/conteudos) — a collection of code written while learning iOS development, from the language fundamentals to a full app with authentication.

## Projects

| Project | Description | Stack |
| --- | --- | --- |
| [`fundamentos-swift`](fundamentos-swift) | Swift language fundamentals — variables, types, classes, optionals — plus a first SwiftUI "Hello, world!". | Swift Playgrounds, SwiftUI |
| [`Reminder`](Reminder) | A UIKit app (ViewCode + MVVM-C) with Firebase email/password login and `UserDefaults` persistence. | UIKit, Firebase Auth, CocoaPods |

Each project has its own README with details on what it covers and how to run it.

## Topics covered across the course

- **Swift language** — variables vs. constants, types, classes, initializers, optionals, optional binding (`if let` / `guard let`).
- **SwiftUI basics** — `App` entry point, `Scene`, simple views.
- **UIKit & ViewCode** — building interfaces programmatically with Auto Layout.
- **Architecture** — MVVM-C (Model–View–ViewModel + Coordinator), dependency injection.
- **Authentication** — Firebase email/password sign-in.
- **Persistence** — storing a `Codable` model in `UserDefaults`.

## Requirements

- macOS with **Xcode 15+**
- [CocoaPods](https://cocoapods.org) (for the `Reminder` project)
- [Swift Playgrounds](https://www.apple.com/swift/playgrounds/) (optional, for the playgrounds)
